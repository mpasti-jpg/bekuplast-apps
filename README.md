# Bekuplast Apps

Prosta aplikacja startowa dla narzedzi i procesow zespolu Bekuplast, zbudowana w Vite, React i TypeScript.

## Wymagania

- Node.js 20 lub nowszy
- npm

## Uruchomienie

```bash
npm install
npm run dev
```

## Dostepne skrypty

- `npm run dev` - uruchamia lokalny serwer developerski Vite.
- `npm run build` - uruchamia TypeScript i produkcyjny build Vite.
- `npm run preview` - podglad produkcyjnego builda.
- `npm run lint` - uruchamia ESLint dla projektu.

## Struktura

- `src/App.tsx` - glowny widok aplikacji.
- `src/App.css` - style widoku startowego.
- `src/styles.css` - globalne style bazowe.
- `vite.config.ts` - konfiguracja Vite.
